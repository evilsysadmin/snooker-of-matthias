# Snooker of Matthias

A small, playable 3D billiards experiment in the ShadowOps family.

The first milestone is a browser-based 3D table, cue aiming and realistic-enough ball physics. Staging target: `staging.snooker.shadowops.dpdns.org` via Cloudflare Pages (owned by ShadowOps Infra).

See `AGENTS.md` and the application README in subsequent commits for development and delivery guidance.
